# Calculadora de IMC em Python

Projeto desenvolvido para a disciplina de Linguagens de Programação.

# Sobre o projeto

Aplicação com interface gráfica desenvolvida em Python utilizando a biblioteca Tkinter, que permite calcular o Índice de Massa Corporal (IMC).

# Funcionalidades

- Cadastro do nome e endereço do paciente.
- Entrada de altura e peso.
- Cálculo e classificação do IMC.
- Opções para calcular, reiniciar e sair.

# Como executar

É necessário ter o Python instalado.

```bash
python calculadora_imc.py
```

# Tecnologias utilizadas

- Python
- Tkinter
- Programação Orientada a Objetos (POO)
